# ADR-0003: Explicit hints and reference Rust policy

Status: accepted for Foundation preview. Use typed task hints rather than keyword classification or repository size heuristics. Pure Rust policy expresses Medium/High and preferred capability with honest fallback. Discovery is evidence of an executable only, not a verified integration. Launch remains passthrough until safe config/capability compatibility gates are complete. Do not disable user MCP/plugins or guess profile semantics. This leaves automated tool-surface application to Router v2.
