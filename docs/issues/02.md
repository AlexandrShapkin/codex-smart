# P0: Bootstrap Rust workspace and CLI

## Context

Thin launcher; minimize cost subject to required correctness and verification.

## Problem and scope

Create minimal core/CLI workspace and stable command parsing with structured error codes.

## Non-goals

No second agent, custom MCP/vector database, hidden installations or unrelated framework.

## Acceptance criteria

Version comes from workspace; unsupported args fail; doctor/explain executable; zero hidden installs.

## Validation

workspace tests, fmt, clippy, build
