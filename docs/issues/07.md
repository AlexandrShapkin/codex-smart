# P0: Pin and report external capability versions

## Context

Thin launcher; minimize cost subject to required correctness and verification.

## Problem and scope

Record versions without arbitrary wrapper execution and define supported command/transport matrix.

## Non-goals

No second agent, custom MCP/vector database, hidden installations or unrelated framework.

## Acceptance criteria

Rust/CLI versions documented; runtime pins explicit; incompatible/unknown tools not declared ready; no network installs.

## Validation

stub version compatibility matrix; offline diagnostic tests
