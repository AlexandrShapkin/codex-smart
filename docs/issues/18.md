# P0: Launch Codex safely with exact OS arguments

## Context

The launcher must hand off to one coherent Codex session without acting as a second agent.

## Problem and scope

Resolve Codex on a constrained PATH, prepare an absolute executable plan, support read-only dry-run, launch without a shell and preserve argument bytes, exit status and Unix signals. Recheck executable identity immediately before execution.

## Non-goals

No profile generation, MCP activation, version auto-installation or claims of race-free execution; PATH ownership/ancestor trust and descriptor execution remain hardening work.

## Acceptance criteria

- Explicit run and implicit passthrough work; reserved names can be escaped with `--`.
- Shell metacharacters are literal; non-UTF8 argv is preserved.
- Dry-run performs no execution or filesystem mutation and omits argument values.
- Missing/changed executable produces stable error code without reflecting secrets.
- Unix process replacement preserves exit code and signal termination.
- User Codex config/MCP/plugins/auth are not edited.
- Local checks pass and committed branch/remote CI evidence is recorded before closure.

## Validation

Isolated fake Codex tests: injection strings, argument bytes, dry-run tree snapshots, missing/replaced executable, exit 37, SIGTERM and default launch. `just check` and nextest.
