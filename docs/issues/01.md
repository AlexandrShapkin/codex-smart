# P0: Establish repository provenance and baseline

## Context

Thin launcher; minimize cost subject to required correctness and verification.

## Problem and scope

Record artifact checksums and distinguish supplied 1.4.0 evidence from unverified 1.4.1. Preserve brief unchanged; import no legacy code without artifact and license verification.

## Non-goals

No second agent, custom MCP/vector database, hidden installations or unrelated framework.

## Acceptance criteria

Provenance doc identifies uncertainty; available input SHA-256 recorded; future legacy isolated.

## Validation

sha256sum and source evidence review

## Dependencies

None.
