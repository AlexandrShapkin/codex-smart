## Implemented acceptance evidence

The local aggregate layer now consumes only the normalized benchmark-record contract.
It rejects unexpected/raw-like fields without reflecting their contents and contains no
network exporter. Missing counters remain unknown (`samples=0`, null aggregate values).
Cold/warm classification and setup/index/bootstrap overhead have explicit aggregate
slots; the accepted baseline correctly leaves unavailable overhead unknown.

Collection requires an explicit `--records-dir`. Scenario-level breakdown is a second
explicit opt-in (`--include-scenario-breakdown`). Optional file output is exclusive and
private (0600); default output is stdout. The telemetry schema is
`benchmarks/schema/telemetry.schema.json`. The accepted representative records produce a
sanitized 40-record integration snapshot at `benchmarks/representative-telemetry-v1.json`
(SHA-256 `359b01bcabd104a5b02289be9d9fdb599d0831acbbdf676514acc9fd7a2686a7`).
No raw trace, stderr, prompt, source, credentials or arbitrary failure text is present.

Validation includes privacy-field refusal/no-reflection, unknown-counter semantics,
cold/warm/overhead aggregation, explicit scenario-breakdown opt-in, symlink rejection,
private exclusive output, schema integration and the accepted 40-run snapshot.
